# 🎬 Video Generator Bot

Telegram-бот, который генерирует видео на **бесплатных** нейросетях с Hugging Face Spaces:

| Что отправить боту | Что получишь |
|---|---|
| Текст (или `/video описание`) | Видео по описанию (LTX-Video / Wan 2.1) |
| Фото → «✨ Оживить» (в подписи можно описать движение) | Анимированное фото |
| Фото с лицом + видео (альбомом или по очереди) | То же видео с заменённым лицом |
| Альбом из 2 фото (лицо, потом цель) | Фото с заменённым лицом |

Готовое видео обрабатывается через ffmpeg: плавное появление и затухание, H.264, быстрый старт в Telegram.
Пока идёт генерация, в чате крутится анимированный прогресс-бар.

> ⚠️ Замену лица используй только со своими лицами или с согласия людей. Не выдавай результат за настоящую запись.

## Как это работает

Бот не требует GPU — он вызывает публичные бесплатные Spaces через `gradio_client`.
Названия моделей задаются в `.env` (можно несколько через запятую — бот переключится на следующую, если одна упала).
Эндпоинт и параметры спейса бот находит сам по описанию его API, поэтому можно подставить почти любой видео/face-swap Space.
Если автоподбор выбрал не тот эндпоинт — укажи его явно: `owner/space@/api_name`.

Бесплатный `HF_TOKEN` (https://huggingface.co/settings/tokens) не обязателен, но даёт больше бесплатной GPU-квоты.

## Запуск локально

```bash
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN от @BotFather
python main.py         # работает через long polling
```

Для постобработки нужен `ffmpeg` (без него видео отдаётся как есть).

## Деплой на Render (бесплатно)

1. New → **Blueprint** → выбрать этот репозиторий (подхватится `render.yaml`, сборка из `Dockerfile` с ffmpeg).
2. Заполнить `BOT_TOKEN` и (по желанию) `HF_TOKEN`.
3. Всё. Render сам задаёт `RENDER_EXTERNAL_URL`, и бот переключается в webhook-режим.

Бесплатный инстанс засыпает без трафика — webhook от Telegram его будит, первое сообщение может идти ~30–60 с.

## Структура

```
main.py            запуск: polling локально / webhook на Render
bot/config.py      настройки из .env
bot/hf.py          универсальный вызов Hugging Face Spaces с автоподбором эндпоинта
bot/services.py    сценарии (текст→видео, оживление фото, замена лица) + ffmpeg
bot/handlers.py    логика диалога в Telegram
bot/ui.py          анимированный прогресс
```

## Ограничения

- Telegram даёт ботам скачивать файлы до 20 МБ и отправлять до 50 МБ.
- Бесплатные Spaces бывают перегружены или меняют API — тогда поменяй модель в `.env`.
